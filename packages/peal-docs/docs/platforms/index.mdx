Peal posts to eleven platforms. Each platform's page says:

- how to connect an account;
- what a post there may hold, and the options it takes;
- whether Peal reads its comments;
- what a self-hosted server needs for it.

## What each platform takes [#limits]

These are the limits Peal checks before a post goes out, from the rules the server and every client share. The platform may refuse more, such as a file it cannot read.

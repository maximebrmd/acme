Peal publie sur onze plateformes. La page de chacune dit :

- comment connecter un compte ;
- ce qu’une publication peut y contenir, et les options qu’elle prend ;
- si Peal lit ses commentaires ;
- ce qu’un serveur auto-hébergé demande pour elle.

## Ce que prend chaque plateforme [#limits]

Voici les limites que Peal vérifie avant qu’une publication parte, d’après les règles que partagent le serveur et chaque client. La plateforme peut en refuser davantage, comme un fichier qu’elle ne sait pas lire.

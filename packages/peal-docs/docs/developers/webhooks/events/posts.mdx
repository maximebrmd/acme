The events of a post, each with its fields and an example payload. Events that name a channel carry the [fields of one channel](/developers/webhooks/events#per-channel).

## post.scheduled [#post-scheduled]

A post was scheduled, or moved to another time. A post that waits for an [approval](/guides/posts/review) is not scheduled yet: it sends `post.approval_requested`, and this event only once it is approved.

| Field         | Type   | What it holds                                                                 |
| ------------- | ------ | ----------------------------------------------------------------------------- |
| `workspaceId` | string | The workspace                                                                 |
| `postId`      | string | The post                                                                      |
| `scheduledAt` | string | When it goes out, as an instant in UTC                                        |
| `timeZone`    | string | The IANA time zone it was scheduled in, such as `Europe/Paris`                |
| `targets`     | array  | The channels it goes out on, each with `targetId`, `channelId` and `platform` |

```json title="post.scheduled"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e01",
  "type": "post.scheduled",
  "version": 1,
  "timestamp": "2026-11-09T16:42:10.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "scheduledAt": "2026-11-10T09:00:00.000Z",
    "timeZone": "Europe/Paris",
    "targets": [
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
        "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
        "platform": "mastodon"
      },
      {
        "targetId": "019a6f3e-8c2b-7d03-b5c2-0f4e8a1d3c26",
        "channelId": "019a5d12-9b0e-7e44-9d1f-2c3b4a5d6e7f",
        "platform": "bluesky"
      }
    ]
  }
}
```

## post.unscheduled [#post-unscheduled]

A scheduled post, or one that waited for an approval, was taken back to draft: it goes out nowhere until it is scheduled again.

| Field         | Type   | What it holds |
| ------------- | ------ | ------------- |
| `workspaceId` | string | The workspace |
| `postId`      | string | The post      |

```json title="post.unscheduled"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e02",
  "type": "post.unscheduled",
  "version": 1,
  "timestamp": "2026-11-09T17:05:44.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01"
  }
}
```

## post.published [#post-published]

The post went live on the channel.

| Field         | Type           | What it holds                                                                                           |
| ------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                                                           |
| `postId`      | string         | The post                                                                                                |
| `targetId`    | string         | The post on that channel                                                                                |
| `channelId`   | string         | The channel                                                                                             |
| `platform`    | string or null | The channel's platform; null once the channel was disconnected                                          |
| `round`       | integer        | How many times the post was sent there                                                                  |
| `publishedAt` | string         | When it went live, as an instant in UTC                                                                 |
| `permalink`   | string or null | Its address on the platform, when the platform gave one, or the member who confirmed it; null otherwise |

```json title="post.published"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e03",
  "type": "post.published",
  "version": 1,
  "timestamp": "2026-11-10T09:00:03.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
    "platform": "mastodon",
    "round": 1,
    "publishedAt": "2026-11-10T09:00:02.000Z",
    "permalink": "https://social.example/@peal_example/115512345678901234"
  }
}
```

## post.failed [#post-failed]

The post did not go out on the channel.

| Field         | Type           | What it holds                                                  |
| ------------- | -------------- | -------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                  |
| `postId`      | string         | The post                                                       |
| `targetId`    | string         | The post on that channel                                       |
| `channelId`   | string         | The channel                                                    |
| `platform`    | string or null | The channel's platform; null once the channel was disconnected |
| `round`       | integer        | How many times the post was sent there                         |
| `failedAt`    | string         | When it failed, as an instant in UTC                           |
| `reason`      | string         | Why, one of the codes below                                    |

| `reason`              | What happened                                                                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `contentRejected`     | The platform refused the post's text or format.                                                                                                   |
| `channelDisconnected` | The channel was disconnected from the workspace before the post went out. Nothing was sent.                                                       |
| `channelDisabled`     | The channel was turned off before the post went out. Nothing was sent.                                                                            |
| `mediaRemoved`        | One of its images or videos was deleted, or was no longer ready, before the post went out. Nothing was sent.                                      |
| `mediaRejected`       | The platform refused one of its images or videos.                                                                                                 |
| `missed`              | The server was down at the scheduled time, and the post was too late to send when it came back.                                                   |
| `notPublished`        | A member checked an unconfirmed post on the platform and did not find it.                                                                         |
| `rateLimited`         | The platform kept limiting Peal until the attempt gave up.                                                                                        |
| `tokenExpired`        | The platform refused the channel's authorization: the channel must be reconnected.                                                                |
| `unavailable`         | The platform could not be reached. Nothing was sent.                                                                                              |
| `appNotAudited`       | The platform takes only some posts from the server's app until it approves it. Nothing was sent.                                                  |
| `quotaExceeded`       | A daily allowance of uploads on the platform stayed used up until the attempt gave up.                                                            |
| `appBillingLimit`     | The platform refused the server's app until its operator pays for it. Nothing was sent.                                                           |
| `planLimit`           | The workspace's plan had no room for the post when it was due: too many channels, or the month's posts used up. Nothing was sent.                 |
| `partsNotSent`        | Some parts of the post are live, and Peal cannot send those after them: it has no post to reply to. It cannot be reposted.                        |
| `repliesNotAllowed`   | The first parts are live, and X did not let this server's app post the rest as replies ([Threads](/guides/posts#threads)). It cannot be reposted. |

[Notifications](/guides/workspace/notifications#events) tells what to do about each.

```json title="post.failed"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e04",
  "type": "post.failed",
  "version": 1,
  "timestamp": "2026-11-10T09:00:04.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d03-b5c2-0f4e8a1d3c26",
    "channelId": "019a5d12-9b0e-7e44-9d1f-2c3b4a5d6e7f",
    "platform": "bluesky",
    "round": 1,
    "failedAt": "2026-11-10T09:00:04.000Z",
    "reason": "tokenExpired"
  }
}
```

## post.unconfirmed [#post-unconfirmed]

Peal cannot tell whether the post went live on the channel, and never sends it again on its own: someone checks the platform, then [confirms it or posts it again](/guides/posts/schedule#follow-up).

Once a member says what they found, a `post.published`, or a `post.failed` with the reason `notPublished`, follows for the same `round`. A repost brings the events of the next round.

| Field         | Type           | What it holds                                                  |
| ------------- | -------------- | -------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                  |
| `postId`      | string         | The post                                                       |
| `targetId`    | string         | The post on that channel                                       |
| `channelId`   | string         | The channel                                                    |
| `platform`    | string or null | The channel's platform; null once the channel was disconnected |
| `round`       | integer        | How many times the post was sent there                         |
| `attemptedAt` | string         | When the attempt was made, as an instant in UTC                |
| `reason`      | string         | Why Peal cannot tell, one of the codes below                   |

| `reason`             | What happened                                                                      |
| -------------------- | ---------------------------------------------------------------------------------- |
| `noResponse`         | The request may have reached the platform, and no answer came back.                |
| `unreadableResponse` | An answer came back that Peal could not read.                                      |
| `interrupted`        | The server stopped during the call, so whether it went out is not known.           |
| `adapterFailure`     | Peal's own code failed during the call, after the request may have left.           |
| `stillProcessing`    | The platform took the post and was still processing it when Peal stopped checking. |

```json title="post.unconfirmed"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e05",
  "type": "post.unconfirmed",
  "version": 1,
  "timestamp": "2026-11-10T09:00:21.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
    "platform": "linkedin",
    "round": 1,
    "attemptedAt": "2026-11-10T09:00:01.000Z",
    "reason": "noResponse"
  }
}
```

## post.cancelled [#post-cancelled]

The post was cancelled. `targets` are the channels it will not go out on; a channel it had already reached keeps its own event.

A channel Peal was sending to at that moment ends with its own event: `post.published`, `post.failed` or `post.unconfirmed` if the platform was called, or a `post.cancelled` naming it alone if it was not.

| Field         | Type   | What it holds                                                                        |
| ------------- | ------ | ------------------------------------------------------------------------------------ |
| `workspaceId` | string | The workspace                                                                        |
| `postId`      | string | The post                                                                             |
| `cancelledAt` | string | When it was cancelled, as an instant in UTC                                          |
| `targets`     | array  | The channels it will not go out on, each with `targetId`, `channelId` and `platform` |

```json title="post.cancelled"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e06",
  "type": "post.cancelled",
  "version": 1,
  "timestamp": "2026-11-09T18:30:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "cancelledAt": "2026-11-09T18:30:00.000Z",
    "targets": [
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
        "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
        "platform": "mastodon"
      }
    ]
  }
}
```

## post.finished [#post-finished]

Every channel of the post has its result: it went live, failed, may have gone out, or was cancelled there. `post.published`, `post.failed` and `post.unconfirmed` tell each channel as it ends; this tells the whole post once the last one has, with `outcome`, what they add up to.

It can come more than once:

- a post sent again on a channel finishes again when that round ends, and brings another `post.finished` with its `round`;
- a member who confirms an unconfirmed channel brings one more when that changes `outcome`.

An endpoint that listens to some channels hears it when one of the post's channels is among them.

| Field         | Type    | What it holds                                                                                                                                                                                                                                    |
| ------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `workspaceId` | string  | The workspace                                                                                                                                                                                                                                    |
| `postId`      | string  | The post                                                                                                                                                                                                                                         |
| `outcome`     | string  | What its channels add up to: `published` (every channel has it whole), `partiallyPublished` (some do), `unconfirmed` (at least one may have it: check before anything else), `failed` (none has it) or `cancelled` (every channel was cancelled) |
| `finishedAt`  | string  | When it finished, as an instant in UTC                                                                                                                                                                                                           |
| `round`       | integer | The post's latest round: 1, and one more each time one of its channels was sent again                                                                                                                                                            |
| `targets`     | array   | Each channel's result: `targetId`, `channelId`, `platform`, `status` (`published`, `failed`, `unconfirmed` or `cancelled`), `failureReason` ([why](#post-failed) it failed, or null) and `permalink` (its address there, or null)                |

```json title="post.finished"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e1a",
  "type": "post.finished",
  "version": 1,
  "timestamp": "2026-11-10T09:00:04.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "outcome": "partiallyPublished",
    "finishedAt": "2026-11-10T09:00:04.000Z",
    "round": 1,
    "targets": [
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
        "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
        "platform": "mastodon",
        "status": "published",
        "failureReason": null,
        "permalink": "https://mastodon.example/@peal_example/113456789012345678"
      },
      {
        "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d16",
        "channelId": "019a5d12-9b0e-7e44-9d1f-2c3b4a5d6e7f",
        "platform": "bluesky",
        "status": "failed",
        "failureReason": "rateLimited",
        "permalink": null
      }
    ]
  }
}
```

## post.unpublished [#post-unpublished]

Peal deleted the post from the channel's platform, every part of it, as a member, a key or an application asked ([Unpublish a post](/guides/posts/published#unpublish)). The post stays `published` in Peal: its target gets `removedAt`, and keeps its permalink as a record.

| Field         | Type           | What it holds                                                                  |
| ------------- | -------------- | ------------------------------------------------------------------------------ |
| `workspaceId` | string         | The workspace                                                                  |
| `postId`      | string         | The post                                                                       |
| `targetId`    | string         | The post on that channel                                                       |
| `channelId`   | string         | The channel                                                                    |
| `platform`    | string or null | The channel's platform; null once the channel was disconnected                 |
| `removedAt`   | string         | When the last part was deleted, as an instant in UTC                           |
| `alreadyGone` | boolean        | Whether the platform had a part no longer, as when it was deleted there before |

```json title="post.unpublished"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e21",
  "type": "post.unpublished",
  "version": 1,
  "timestamp": "2026-11-10T09:00:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "targetId": "019a6f3e-8c2b-7d02-8a11-6e2f9b0c7d15",
    "channelId": "019a5d10-41f7-7c3a-a2b9-8d6e0f1a2b3c",
    "platform": "mastodon",
    "removedAt": "2026-11-10T09:00:00.000Z",
    "alreadyGone": false
  }
}
```

## post.unpublish_failed [#post-unpublish-failed]

Peal could not delete the post from the channel's platform, after the tries a deletion makes. `code` says why, as the change's `code` does: `unavailable`, `rateLimited`, `channelUnavailable`, or the platform's own.

The post may still be there, whole or in part. A member may ask again, which deletes the parts left.

| Field         | Type           | What it holds                                                  |
| ------------- | -------------- | -------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                  |
| `postId`      | string         | The post                                                       |
| `targetId`    | string         | The post on that channel                                       |
| `channelId`   | string         | The channel                                                    |
| `platform`    | string or null | The channel's platform; null once the channel was disconnected |
| `code`        | string         | Why the deletion stopped                                       |
| `failedAt`    | string         | When Peal gave up, as an instant in UTC                        |

| `part`        | integer        | The part edited, from 0 (the post itself)                      |

## post.edit_failed [#post-edit-failed]

Peal could not edit the post's part on the channel's platform, after the tries an edit makes. `code` says why, as the change's `code` does: `postGone` when the platform no longer has the post, `pollNotEditable` for a Mastodon post with a poll, `permissionDenied`, `unavailable`, `rateLimited`, `channelUnavailable`, or the platform's own.

Peal's text is unchanged, and the post most likely says what it said before.

<Callout type="warning" title="After unavailable or rateLimited">
  An answer may have been lost, and the platform may show the new text: look
  there before a member asks again.
</Callout>

| `channelId`   | string         | The channel                                                    |
| `platform`    | string or null | The channel's platform; null once the channel was disconnected |
| `part`        | integer        | The part Peal was asked to edit, from 0                        |
| `code`        | string         | Why the edit stopped                                           |
| `failedAt`    | string         | When Peal gave up, as an instant in UTC                        |

## post.approval_requested [#post-approval-requested]

Someone asked for the post to go out, in a workspace that asks for [approvals](/guides/posts/review): it waits. It keeps its time, and no `post.scheduled` is sent until it is approved. What an application sends or schedules there starts this way.

What follows tells what became of it, one of:

- `post.approval_requested` again, with its new `scheduledAt`: it was moved to another time, and still waits;
- [`post.approved`](#post-approved), then `post.scheduled` unless the approval came `late`;
- [`post.changes_requested`](#post-changes-requested): it is a draft again;
- `post.unscheduled`: someone took it back to draft before anyone decided;
- `post.cancelled`: it was cancelled while it waited;
- `post.scheduled` alone: a member who may schedule without an approval scheduled it.

| Field         | Type   | What it holds                                     |
| ------------- | ------ | ------------------------------------------------- |
| `workspaceId` | string | The workspace                                     |
| `postId`      | string | The post                                          |
| `scheduledAt` | string | When it was asked to go out, as an instant in UTC |

```json title="post.approval_requested"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e0a",
  "type": "post.approval_requested",
  "version": 1,
  "timestamp": "2026-11-09T16:40:00.000Z",
  "workspaceExternalId": null,
```

## post.approved [#post-approved]

The post was approved. Approved in time, it is scheduled, and a `post.scheduled` follows. Approved after its time (`late`), nothing goes out late: it is a draft again, and no `post.scheduled` follows.

| Field         | Type    | What it holds                                                                                                         |
| ------------- | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `workspaceId` | string  | The workspace                                                                                                         |
| `postId`      | string  | The post                                                                                                              |
| `by`          | string  | Who approved it, by kind: `member`, `visitor` (someone who came through a review link) or `application`. Never a name |
| `late`        | boolean | Whether its time had passed                                                                                           |

```json title="post.approved"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e0b",
  "type": "post.approved",
  "version": 1,
  "timestamp": "2026-11-09T17:00:00.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "by": "visitor",
    "late": false
  }
}
```

## post.changes_requested [#post-changes-requested]

Changes were asked for on a post that waited: it is a draft again. What was asked is a comment on the post, which the event does not carry: read the post's review through the API.

| Field         | Type   | What it holds                                            |
| ------------- | ------ | -------------------------------------------------------- |
| `workspaceId` | string | The workspace                                            |
| `postId`      | string | The post                                                 |
| `by`          | string | Who asked, by kind: `member`, `visitor` or `application` |

The events of a file in the media library, of the comments under a published post and of the reviews of a location, each with its fields and an example payload. Media events are about no channel, so they reach an endpoint [whatever channels it lists](/developers/webhooks#filters).

## media.ready [#media-ready]

Peal [read the file](/guides/media#library) once it was stored, and it can go in posts.

| Field         | Type   | What it holds                                |
| ------------- | ------ | -------------------------------------------- |
| `workspaceId` | string | The workspace                                |
| `mediaId`     | string | The media                                    |
| `contentType` | string | The file's content type, such as `image/png` |

```json title="media.ready"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e0a",
  "type": "media.ready",
  "version": 1,
  "timestamp": "2026-11-09T16:30:55.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "mediaId": "019a6f21-0d5c-7a90-8e3b-4f5a6b7c8d9e",
    "contentType": "image/png"
  }
}
```

## media.failed [#media-failed]

The file was refused, or Peal could not read it. A file that could not be read stays in the library, and is not ready for posts.

| Field         | Type   | What it holds               |
| ------------- | ------ | --------------------------- |
| `workspaceId` | string | The workspace               |
| `mediaId`     | string | The media                   |
| `reason`      | string | Why, one of the codes below |

| `reason`       | What happened                                                          |
| -------------- | ---------------------------------------------------------------------- |
| `sizeMismatch` | The stored file is not the size the upload declared. It was refused.   |
| `typeMismatch` | The stored file is not the type the upload declared. It was refused.   |
| `unreadable`   | The file is damaged, or not in a format Peal reads.                    |
| `timedOut`     | Reading the file took longer than Peal allows.                         |
| `tooLarge`     | The store served more bytes than Peal stores for the file's kind.      |
| `toolFailed`   | The program that reads files could not run, or printed nothing usable. |
| `tooManyPages` | A PDF document has more than 300 pages, which no platform shows.       |
| `unavailable`  | The instance has nothing to read this kind of file with.               |

```json title="media.failed"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e0b",
  "type": "media.failed",
  "version": 1,
  "timestamp": "2026-11-09T16:31:20.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "mediaId": "019a6f21-0d5c-7a90-8e3b-4f5a6b7c8d9e",
    "reason": "typeMismatch"
  }
}
```

## comment.received [#comment-received]

Peal read a comment for the first time under a post that went live on a channel (see [Inbox](/guides/engage/inbox)). The event carries ids only: what the comment says and who wrote it are read through the API, with `engagement:read`.

| Field         | Type   | What it holds                            |
| ------------- | ------ | ---------------------------------------- |
| `workspaceId` | string | The workspace                            |
| `postId`      | string | The post                                 |
| `channelId`   | string | The channel the post went live on        |
| `threadId`    | string | The thread: the comments under that post |
| `commentId`   | string | The comment                              |
| `receivedAt`  | string | When Peal read it, as an instant in UTC  |

```json title="comment.received"
{
  "id": "019a6f52-1c3d-7e4f-8a5b-6c7d8e9f0a1b",
  "type": "comment.received",
  "version": 1,
  "timestamp": "2026-11-10T09:13:02.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f1c-4b7e-7d3a-9f21-6a5c8e1d2b40",
    "channelId": "019a6e02-9c1d-7b55-8a10-3e4f5a6b7c8d",
    "threadId": "019a6f50-0a1b-7c2d-8e3f-4a5b6c7d8e9f",
    "commentId": "019a6f52-1c3d-7e4f-8a5b-6c7d8e9f0a1a",
    "receivedAt": "2026-11-10T09:13:02.000Z"
  }
}
```

## comment.replied [#comment-replied]

A reply to a comment went out from Peal, as the channel's account. A reply that failed, or whose outcome is not known, sends nothing: read it through the API.

| Field         | Type           | What it holds                                         |
| ------------- | -------------- | ----------------------------------------------------- |
| `workspaceId` | string         | The workspace                                         |
| `postId`      | string         | The post                                              |
| `channelId`   | string         | The channel                                           |
| `threadId`    | string         | The thread                                            |
| `commentId`   | string         | The comment that was answered                         |
| `replyId`     | string         | The reply                                             |
| `permalink`   | string or null | The reply's address on the platform, when it gave one |
| `repliedAt`   | string         | When it went out, as an instant in UTC                |

```json title="comment.replied"
{
  "id": "019a6f58-2d4e-7f5a-9b6c-7d8e9f0a1b2c",
  "type": "comment.replied",
  "version": 1,
  "timestamp": "2026-11-10T09:20:41.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f1c-4b7e-7d3a-9f21-6a5c8e1d2b40",
    "channelId": "019a6e02-9c1d-7b55-8a10-3e4f5a6b7c8d",
    "threadId": "019a6f50-0a1b-7c2d-8e3f-4a5b6c7d8e9f",
    "commentId": "019a6f52-1c3d-7e4f-8a5b-6c7d8e9f0a1a",
    "replyId": "019a6f57-3e5f-7a6b-8c7d-8e9f0a1b2c3d",
    "permalink": "https://mastodon.example/@peal_example/113000000000000002",
    "repliedAt": "2026-11-10T09:20:41.000Z"
  }
}
```

## review.received [#review-received]

Peal read a review for the first time on a location a Google Business Profile channel posts as (see [Inbox](/guides/engage/inbox#reviews)). The event carries ids only: the review's stars, what it says and who wrote it are read through the API, as Google lets what its API gives be stored 30 days at most and an event is kept with its deliveries, with `engagement:read`.

| Field         | Type   | What it holds                            |
| ------------- | ------ | ---------------------------------------- |
| `workspaceId` | string | The workspace                            |
| `channelId`   | string | The channel whose location was reviewed  |
| `threadId`    | string | The thread: the reviews of that location |
| `reviewId`    | string | The review                               |
| `receivedAt`  | string | When Peal read it, as an instant in UTC  |

```json title="review.received"
{
  "id": "019a8163-4a1b-7c2d-8e3f-4a5b6c7d8e01",
  "type": "review.received",
  "version": 1,
  "timestamp": "2026-11-14T09:27:04.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "channelId": "019a6e02-9c1d-7b55-8a10-3e4f5a6b7c8d",
    "threadId": "019a8163-2c40-7e1b-a3d5-6f7a8b9c0d0f",
    "reviewId": "019a8163-2c40-7e1b-a3d5-6f7a8b9c0d10",
    "receivedAt": "2026-11-14T09:27:04.000Z"
  }
}
```

## review.replied [#review-replied]

A reply to a review went out from Peal, as the location. A reply that failed, or whose outcome is not known yet, sends nothing: read it through the API.

| Field         | Type   | What it holds                          |
| ------------- | ------ | -------------------------------------- |
| `workspaceId` | string | The workspace                          |
| `channelId`   | string | The channel                            |
| `threadId`    | string | The thread                             |
| `reviewId`    | string | The review that was answered           |
| `replyId`     | string | The reply                              |
| `repliedAt`   | string | When it went out, as an instant in UTC |

```json title="review.replied"
{
  "id": "019a8163-5b2c-7d3e-8f4a-5b6c7d8e9f02",
  "type": "review.replied",

  "timestamp": "2026-11-14T09:40:12.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",

    "threadId": "019a8163-2c40-7e1b-a3d5-6f7a8b9c0d0f",
    "reviewId": "019a8163-2c40-7e1b-a3d5-6f7a8b9c0d10",
```

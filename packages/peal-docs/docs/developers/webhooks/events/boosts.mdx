## Boost events [#boost-events]

A [boost](/guides/engage/boosts#boosts) promotes a published post as an ad, on an instance where [ads](/guides/engage/ads) are on. Its eight events carry the same `data`: ids, amounts and where the boost stands.

They never carry who the boost is shown to, nor who benefits from the ad or pays for it: read the boost through the API for that, with `GET /api/workspaces/{workspaceId}/ads/boosts/{boostId}`.

| Field         | Type           | What it holds                                                                                                                                                        |
| ------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `workspaceId` | string         | The workspace                                                                                                                                                        |
| `postId`      | string         | The post the boost promotes                                                                                                                                          |
| `boostId`     | string         | The boost                                                                                                                                                            |
| `adAccountId` | string         | The ad account that pays for it                                                                                                                                      |
| `budget`      | object         | Its budget: `amount`, an integer in the ad account's [minor units](/guides/engage/boosts#money), and `kind`, `total` for the whole run or `daily` for each day of it |
| `committed`   | integer        | The most it can cost, in minor units: what is counted against the account's [monthly ceiling](/guides/engage/boosts#ceiling)                                         |
| `currency`    | string         | The ad account's currency, as an ISO 4217 code such as `EUR`                                                                                                         |
| `endsAt`      | string         | When its run ends, as an instant in UTC                                                                                                                              |
| `state`       | string         | Where the boost stands, one of the [boost states](/guides/engage/boosts#states)                                                                                      |
| `reason`      | string or null | Why it failed, one of the [failure reasons](/guides/engage/boosts#failure-reasons); null unless `state` is `failed`                                                  |

An amount is an integer, never a decimal: `5000` in `EUR` is 50.00 €, and in a currency without a minor unit, such as `JPY`, it is 5,000 ¥. The ad account's `minorUnitDigits`, in the API, says which.

## boost.started [#boost-started]

The boost was made at the ad network and turned on: it may spend up to its budget, until `endsAt`. The network can still review the ad before it shows it.

```json title="boost.started"
{
  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e10",
  "type": "boost.started",
  "version": 1,
  "timestamp": "2026-11-12T09:00:41.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
    "postId": "019a6f3e-8c2a-7b1e-9f40-3d5a1c2b4e01",
    "boostId": "019a7a10-5c3e-7d21-8b40-2e6f9a1c3d01",
    "adAccountId": "019a7902-1f4b-7a60-9c12-7d8e0f2a4b55",
    "budget": {
      "amount": 5000,
      "kind": "total"
    },
    "committed": 5000,
    "currency": "EUR",
    "endsAt": "2026-11-19T09:00:00.000Z",
    "state": "active",
    "reason": null
  }
}
```

```json title="boost.paused"

  "type": "boost.paused",
  "version": 1,
  "timestamp": "2026-11-13T15:20:07.000Z",

  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
```


## boost.stopped [#boost-stopped]

A member stopped the boost for good: it does not run again. `committed` is counted down to what it can have cost: nothing if it never ran, the days it ran for a daily budget, its whole budget for a total one.

```json title="boost.stopped"

  "id": "019a6f40-2f6b-7a1c-9d2e-5b4c3a2f1e13",
  "type": "boost.stopped",
  "version": 1,
  "timestamp": "2026-11-15T11:45:12.000Z",
  "workspaceExternalId": null,
  "data": {
    "workspaceId": "7b1f6c1e-2d4a-4f0b-9c3e-5a8d2e6f1b90",
```

## boost.unconfirmed [#boost-unconfirmed]

Peal told the network to run the boost and could not read back whether it does. Its budget stays counted, and Peal sends nothing more on its own.

  must not run.

## boost.budget_reached [#boost-budget-reached]

The ads Peal read show that the boost spent its whole total budget: the network no longer shows it. It is sent once, for a total budget only, after the hourly read that found it; the boost stays `active` until its end date.

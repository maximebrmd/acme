Peal is a social media scheduling platform: write a post once, schedule it across platforms, and see how it performs.

<Callout type="warning" title="Early development">
  Peal is being built in the open and has not been released yet. These pages
  describe what works today, and grow as features land.
</Callout>

What works today:

- workspaces;
- Mastodon, Bluesky, LinkedIn, X, Threads and Instagram accounts, and Facebook Pages;
- posts with images and videos, scheduled on a calendar and published;
- a notice of how each post went, and how it did on its platforms;
- a writing assistant.

## What Peal does [#what-it-does]

| Task                      | What Peal does                                                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Write once                | Draft a post in one editor, then give it its own text on each channel where it needs to differ. Counters show how much room each platform leaves. |
| Schedule across platforms | Pick the accounts and the time. Peal publishes each post when it is due, in the time zone you scheduled it in, daylight saving included.          |
| See results               | Peal reads back each post's likes, reposts, replies and quotes for a month, so you can see what worked in one place.                              |
| Work as a team            | Workspaces have members and roles, so several people can write, review and schedule together.                                                     |

<Callout type="info" title="No blind retries">
  When a platform does not confirm whether a post went out, Peal asks again only
  in ways that cannot post it twice. If that still settles nothing, it marks the
  post unconfirmed and asks you to check the platform before posting again.
</Callout>

## Self-hostable [#self-hostable]

Every outside service Peal relies on has a self-hostable default. A self-hosted instance needs:

- Postgres;
- an S3-compatible store;
- a way to send email.

Billing, captcha, AI and telemetry are optional. [Self-hosting](/self-hosting) explains how to run it, [Environment variables](/self-hosting/environment-variables) lists every setting, and the [staff console](/self-hosting/staff) is where the people who run it find accounts and workspaces.

## Fair source [#fair-source]

The source is public under the Functional Source License (FSL-1.1-ALv2):

- You may use, modify and self-host Peal for any purpose, except offering it to others as a competing commercial product or service.
- Each release also becomes available under the Apache License 2.0 two years after it ships.

That is why Peal calls itself fair source rather than open source.
